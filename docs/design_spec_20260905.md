# 구조적 적정가치 모형 (SFV) — 설계 명세

> 작성 2026-09-05. 상태: **승인 후 단계 0~7 구현 완료 (2026-09-06)**. 이 문서는 원안과 사전 등록 기준(2.5절), 단계별 진행·판정 기록(5-1절)을 담는다. 현재 사양은 `FRAMEWORK.md`, 결과 색인은 `reports/INDEX.md`.
> 목적: 개별 종목 횡단면에서 "지금 가격이 왜 여기 있는가"를 펀더멘털·구조적 수요·일시적 수급·잔차로 분해하고,
> 각 성분의 향후 수익률 예측력을 검증한 뒤 실전 판단 도구로 만든다. 논문이 목적이 아니다.
> 이 문서는 구현 전에 쓴 설계 명세의 사본이다. 사전 등록 판정 기준(2.5절)은 구현 전에 고정했고, 5-1절은 그 뒤의 진행과 판정 기록이다.

## 0. 한 줄 요약

**가격 = 지속성 조정 펀더멘털 가치 × 구조적 수요 프리미엄 × 일시적 수급 압력 × 잔차.**
네 항을 따로 추정하고, 각 항이 향후 수익률을 어떻게 예측하는지로 모형의 정당성을 판정한다.
현재 가격이 적정하게 나오도록 보정하는 모형은 정보량이 0이므로, **예측 검정을 통과하지 못하면 폐기**한다.

## 1. 문제 정의와 문헌이 이미 확정한 사실

### 1.1 출발점의 재정의
- "DCF가 시장을 설명 못 한다"는 진단은 부정확하다. 2026-07 Damodaran 내재 ERP 4.42%는 역사 평균 수준이다. 컨센서스 현금흐름을 받아들이면 현재 지수는 정상 위험프리미엄으로 재현된다.
- 충돌은 할인 틀이 아니라 **"현재 마진·성장·초과수익의 지속성"** 과 **"누가 수요를 공급하는가"** 두 가지로 환원된다. 이 문서의 모형은 정확히 그 둘을 추정한다.
- 고평가는 시장 전체가 아니라 상위 집중 종목에 몰려 있다 (Mag 7 제외 493종목 선행 P/E 약 17~18배, 2026-09 기준). 따라서 분석 단위는 **개별 종목 횡단면**이다.

### 1.2 이미 확정된 실증 사실 (모형 설계의 제약조건)

|---|---|---|
| 횡단면 P/E 분산의 약 75%는 향후 수익률 차이, 25%만 이익성장 차이로 실현 | Delao·Han·Myers 2025 JFE | 멀티플 차이의 대부분은 할인율/미스프라이싱. "기준가치 상승" 주장은 횡단면에서 약하다. 모형은 멀티플을 주로 수요·할인율 성분에 귀속시켜야 한다 |

| 무형자산을 자본화하면 ROIC 상승과 분산의 상당 부분이 사라짐 | Ayyagari·Demirgüç-Kunt·Maksimovic 2018 | "슈퍼스타 지속성 증가"는 무형자산 측정오차일 수 있다. 지속성 추정은 반드시 무형자산 조정 후에 한다 |

### 1.3 Novelty 판정
세 모듈 각각은 확립된 문헌이 있다. **세 모듈을 하나의 종목 수준 분해식으로 결합하고, 구조적 수요와 일시적 수급을 분리해 각각의 수익률 예측 계수를 추정한 작업은 검색 범위에서 찾지 못했다.** 가장 가까운 것은 Koijen·Richmond·Yogo 2024 REStud의 투자자 유형별 밸류에이션 분해와 HBS 2026 워킹페이퍼 "Short versus Long-run Demand Elasticities"다. 전자는 13F 전체를 쓰는 구조모형이라 무겁고, 후자는 이론 쪽이다. 실용 도구로서의 공백은 실재한다. 다만 논문이 목적이 아니므로 novelty는 부차적이다.

## 2. 모형

### 2.1 항등식
```
log P_it = log V_F,it + δ_S,it + δ_T,it + ε_it
```
| 항 | 정의 | 예상 성질 | 수익률 예측 부호 |
|---|---|---|---|
| V_F | 무형자산 조정 + 지속성 추정 잔여이익모형(RIM) 가치 | 펀더멘털 | log(P/V_F) ↑ → 수익률 ↓ |
| δ_S | 구조적 수요 프리미엄 (BMI·패시브 지분·지수편입·순발행 축소) | 지속적. 수요가 유지되는 한 되돌림 없음 | 음(−)이되 작음. "설명되지만 기대수익률을 낮춤" |
| δ_T | 일시적 수급 압력 (펀드·ETF 흐름 유발 매매, 3~6개월 누적) | 1~2년 내 되돌림 | 음(−), 강함 |
| ε | 잔차 미스프라이싱 | 수렴 | 음(−), 가장 강함 |

기대수익률 산출:
```
E[r_i] ≈ r_f + β_i·ERP_t  −  λ_F·log(P/V_F)  −  λ_S·δ_S  −  λ_T·δ_T  −  λ_ε·ε
```
λ는 Fama-MacBeth 회귀로 추정한다. 이 식이 도구의 최종 출력이다.

### 2.2 모듈 F — 지속성 조정 펀더멘털 가치
- **틀**: 잔여이익모형 (Ohlson 1995). `V = B_adj + Σ (ROE_adj,t+τ − r)·B_adj,t+τ−1 / (1+r)^τ + TV`
- **무형자산 조정**: R&D 전액 자본화(상각 15%), SG&A 30% 자본화(상각 20%). 조정 장부가 `B_adj = B + K_int`, 조정 이익 `E_adj = E + 당기 자본화액 − 상각`.
- **지속성 (핵심)**: 초과 ROE의 감쇠 `(ROE_adj − ROE*)_{t+τ} = ω^τ · (ROE_adj − ROE*)_t`. ω를 가정하지 않고 패널 회귀로 추정한다.
  `ω_it = ω_0 + ω_1·무형집약도 + ω_2·매출총이익률 안정성 + ω_3·산업집중도 근사 + ω_4·규모 + ω_5·연령 + 시대 더미`
  추정은 **t 시점 이전 데이터만** 쓰는 확장 윈도우로 한다. ROE*는 산업 중앙값 또는 자본비용.
  부속 가설: 무형자산 조정 후에도 시대 더미가 유의하게 커지는가 (슈퍼스타 지속성 증가 vs 측정오차). 어느 결과든 보고.
- **성장**: 청산잉여관계 + 총주주환원율(배당 + 순자사주매입).
- **할인율**: 종목별 `r_f + β·ERP_t` (Damodaran 월별 내재 ERP). 별도로 Hou·van Dijk·Zhang식 ICC를 역산해 기대수익률 지표로 쓴다.
- **금융업**: RIM은 금융업에 적합하나 무형자산 규칙이 다르므로 1차에서는 제외, 2차에서 별도 규칙으로 편입.

### 2.3 모듈 D — 구조적 수요와 일시적 수급
**구조적 변수 (월별)**
- BMI 근사: `Σ_k w_ik · AUM_k`, k ∈ {S&P 500/400/600, Russell 1000/2000, Nasdaq 100, 주요 스타일·섹터}. 현재 가중치는 발행사 ETF 보유파일, 과거는 N-PORT(2019~)와 13F(2013~2019)로 재구성.
- 패시브 지분: 패시브 ETF·인덱스펀드 보유 / 발행주식수.
- 지수 편입 더미·가중치.
- 순발행: 12개월 발행주식수 로그변화 (음수 = 자사주 매입에 의한 공급 축소). XBRL `dei` 태그.

**일시적 변수 (월별)**
- 펀드 FIT (Lou 2012): `FIT_i,t = Σ_j flow_j,t · w_ij,t−1 · TNA_j,t−1 / MktCap_i`. N-PORT의 월별 보유·유출입으로 계산. 2019-08 이후.
- ETF-FIT: 기존 ETF 자금흐름 연구 데이터로 동일 식 계산. 레짐별 승수 검정에 활용.
- 종목 승수는 자체 추정(도구변수: 펀드 흐름의 종목 외생 부분)과 문헌값(0.3~1.5)을 대조한다.

### 2.4 모듈 S — 분해와 검증
1. 월별 횡단면 회귀: `log(P/V_F)_it = a_t + b_S'X_S + b_T'X_T + 산업FE + ε_it` → δ_S, δ_T, ε 산출.
2. 예측 회귀 (Fama-MacBeth, Newey-West): `r_i,t+h = c + λ_F log(P/V_F) + λ_S δ_S + λ_T δ_T + λ_ε ε + 규모·모멘텀·베타·퀄리티 통제`, h ∈ {1, 3, 12개월}.
3. 포트폴리오 검정: 복합점수 10분위, 시총가중 롱숏, 거래비용 반영.
4. **벤치마크**: B/M, E/P, Bartram·Grinblatt 동료내재가치, Hou·van Dijk·Zhang ICC. 이들을 이기지 못하면 결합의 가치가 없다고 보고한다.
5. **표본외**: 확장 윈도우. ω·λ 모두 t 이전 데이터로만 추정.
6. **집계 환원**: 종목 δ_S의 시총가중 합 = "지수 수준 중 구조적 수요 프리미엄 몫". 원래 질문("기준가치가 올라갔는가")에 대한 정량 답.

### 2.5 사전 등록 판정 기준 (구현 전에 고정)
| 판정 | 조건 |
|---|---|
| 모형 채택 | λ_ε, λ_T 유의(t > 2.5, NW), 복합점수 롱숏이 Bartram·Grinblatt 대비 표본외 샤프 우위 |
| 부분 채택 | 잔차·일시 성분만 유의, 구조 성분 무의미 → 구조 모듈 제거 후 도구화 |
| 폐기 | 벤치마크 대비 우위 없음 → 결과 문서화 후 종료. 실패도 보고한다 |

### 3.1 생존편향 대응
- **1차 경로 (채택)**: 검증용 수익률은 로컬 13F 벌크의 내재가격(`value·1000/shares`)으로 만든다. 기존 `build_stock_returns.py` 경로. 상장폐지·피인수 종목도 마지막 보유 분기까지 가격이 있으므로 생존편향이 없다. 대가는 **분기 빈도**와 2013Q2 이후 한정이다. 따라서 검정 지평 h는 1·2·4분기로 잡는다.
- **2차 경로**: yfinance 월별 가격은 현재 시점 도구 출력과 월별 보조 검정에만 쓴다. 월별 결과는 생존편향이 있다고 명시한다.
- 유니버스는 가격이 아니라 **XBRL 제출사 기준**으로 매 분기 구성한다. 13F에서도 가격이 사라진 종목은 상장폐지 후보로 표시하고 (a) 제외 (b) 마지막 관측 후 −30% 부과 두 가지로 민감도 분석해 범위로 보고한다.
- 도구의 1차 목적은 현재 시점 판단이므로 편향이 도구 자체를 무효화하지는 않는다. 다만 월별 백테스트 수치를 그대로 믿지 않는다고 문서에 명시한다.

(3) `p_achieve_3y` 로짓 기저율(요구 성장 z −87, 직전 1년 성장 +7.2, 규모 −5.6, ROE 무의미, 산업 유의; 의사 R² 0.42; 최신 월 중앙값 13%, 상위 50 9%). 표·HTML·what_if(수익률 축, `--growth` 수익률, 분기별 요구 성장 추이)·포스터·FRAMEWORK 2.6절·5절 갱신. 사용 방식 확인: 프리미엄 자체는 판단에 안 쓰고, 가격이 전제하는 성장·할인율을 읽어 판단하고, 실적 뒤 다시 읽는다(애플 요구 성장 34.8% → 21.7%, 직전 1년 매출성장 2% → 14%). 초대형주의 점 추정 가치가 무의미한 것은 도구의 결함이 아니다 — 역산 쪽은 초대형주에서 가장 안정적(g* 구간 1.5~4.1%p). **정방향 시나리오 모드·매수일 대조표·유통량 검사 (2026-09-12, 사용자 요청).** (1) 사용자 질문 "실무에서 쓸 만한가, 기존 밸류에이션을 대체하나": 대체가 아니라 앞단의 층이며(기대투자·HOLT와 같은 발상의 자기 판본), 견해를 만드는 일은 사용자 몫. "정확도"는 기존 DCF도 측정된 적 없음. 못한 부분(정형 경로, 후행 이익, 목표가 부재)을 고치기로 함 → `what_if.py --rev-growth/--margin/--e0/--consensus`: 매출 성장·조정 이익률 경로 → 이익 경로 → 마지막 해 ROE에서 추정 감쇠 → 가치·주당 목표가·그 경로의 수익률·구성·3년 CAGR의 역사적 실현 비율. 적자 기업도 평가 가능. 컨센서스는 yfinance `revenue_estimate`(회계연도→TTM 근사). (2) `--since 매수일`: 그날 요구 성장 vs 이후 실현 매출·이익 누적(달성/미달), 전제 이동을 P/E·할인율로 분해(애플 2024-12 34.8% → 실현 이익 연 21.8% 미달이나 P/E 37→33으로 요구 21.7%; 엔비디아 2023-06 63.4% → 실현 연 173% 달성). (3) `--history 0`: 2014-06 이후 분기별 요구 성장 전체(엔비디아 5% → 2023-06 63% → 21%). (4) 사용자 질문 "유통량 적으면 기관이 움직이나": `scripts/fit_by_float.py` — 흐름 승수 1~5로 유의하나 패시브·기관·지수펀드 지분, 유통량 대용치, 규모 3분위 어디서도 단조 패턴 없음(상호작용 |t| ≤ 1). (5) 감쇠 정정: 형태는 가정, 속도 ω는 추정, 목표 수준은 선택; 감쇠는 산업 축소가 아니라 초과 ROE의 산업 수준 수렴. 요구 성장 수준은 조정 P/E(순위상관 +0.84)·할인율(+0.39)이 정하고 장부·자본화는 그 구간 폭만 정함. (6) 기간별(2014~17/18~20/21~23) 3년 달성 비율 표 추가. 금융업 편입은 별도 작업으로 남김.

**데이터센터 관련주 확인 → 유니버스 분류 결함 수정 (2026-09-12).** 사용자가 아이렌 같은 적자 데이터센터 전환 기업의 역산을 물음. 확인 결과 채굴→데이터센터 전환사 13곳이 SEC의 SIC 6199(기타 금융)로 분류돼 금융 제외에 걸려 있었음 → `universe.NONFINANCIAL_OVERRIDES`로 포함, FF12는 BusEq로 고정(Money로 두면 유니버스 안 Money 그룹이 적자 채굴사뿐이라 감쇠 목표 ROE가 −20%가 되는 2차 결함을 시험에서 잡음). 헤드라인 미세 변동: 시총가중 log(P/V_F) 0.817 → 0.805, ω* 0.9596, g* vw 20.2%, 유니버스 1,887. 적자 기업 역산 `--solve-growth/--solve-margin` 추가(아이렌: 이익률 30→40%면 5년간 연 90% 매출 성장 요구, 기저율 3%). 한계: 장부 음수 기업(코어사이언티픽) 평가 불가, IFRS 공시 기간 미파싱(아이렌 2025-12부터).

**튜토리얼과 경기 국면·초신성 보완 (2026-09-13).** 사용자가 DCF 기초부터 이해가 필요하다고 해 `TUTORIAL.md`(15절) 작성, README 위계 첫 문서. 사용자 질문에 답하며 정정한 것: 위험프리미엄 4.2%는 S&P 500 지수 가격에서 역산한 Damodaran 내재 ERP(2014년 이후 5.0~6.1%, 2026년 4.2%)이며 종목 프리미엄은 β × ERP; 장부가는 자산 − 부채(시총 아님); 요구 지속성 74년은 성장이 아니라 초과 수익성의 지속이며 비현실적이라는 것이 곧 "지속만으로 설명 안 됨"의 뜻. 사용자 순서(성장 견해 → 그때의 수익률 → 판단)가 자연스럽다고 인정. 보완 두 건: (1) 정규화 이익(5년 평균 조정 이익률 × 현재 매출) 기준 g*와 이익 국면 표시(최신 월 33% 표시, 두 g* 차이 중앙값 12%p; 마이크론 17.9% vs 37.6%), (2) 직전 1년 성장 그룹별 조건부 기저율(20~30% 요구 달성 5% / 8% / 21%, 50% 초과 1% / 2% / 5%). what_if에 정규화 g*·이익 국면·직전 성장 무리 기준 기저율 출력. 한국 기업 적용은 사용자가 이해를 먼저 하기로 하여 보류.

**유니버스 누락 결함 수정 (2026-09-13).** 실물자산 기업 예시를 뽑다 엑슨·듀크·서던 부재 발견 → 6월 대비 9월 유니버스에서 245종목 누락(코카콜라·애벗·넥스트에라 포함). 원인 1: SEC companyfacts 기록이 실제 10-Q보다 몇 달 늦음(코카콜라 7-29 제출, 9월 파일과 API 모두 4-30 상태; 6월 유니버스의 11.7%) + 우리 격자가 마지막 공시일+120일까지만 행을 만들어 말없이 탈락 → 400일(has_fund와 동일)로 수정, "재무지연" 표시, selfcheck 37번째(10% 초과 WARN). 원인 2: 대표 증권 규칙이 이틀 차이로 상장 채권(DUKB·SOJD)을 선택 → 최근 120일 내 거래 증권 중 거래일 최다로 변경. 결과: 9월 유니버스 1,887 → 2,015, ΣP 62.3 → 65.7조, ω* 0.961, vw log(P/V_F) 0.78, g* vw 19.9%. 남는 것: 엑슨(승계 CIK 2115436에 재무 없음), 클래스 티커(HEIA·BFA·MOGA) yfinance 미매핑. 튜토리얼에 실물자산 절(3.5) 추가.

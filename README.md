# 구조적 적정가치 (SFV) — 가격이 전제하는 가정을 읽는 도구

미국 비금융 상장사 약 1,900곳에 대해 **지금 주가가 성립하려면 앞으로 10년간 이익이 매년 몇 %씩 자라야 하는지**를 역산하고, 그런 성장이 과거에 얼마나 흔했는지를 나란히 보여 주는 도구입니다. 데이터는 전부 무료 공개 자료(SEC XBRL·13F·N-PORT·FTD, FRED, Damodaran)이고, 모든 계산은 그 시점에 공개돼 있던 값만 씁니다(point in time).

[English summary](README_EN.md) · 튜토리얼 [`TUTORIAL.md`](TUTORIAL.md) · 현재 사양 [`FRAMEWORK.md`](FRAMEWORK.md) · 결과 색인 [`reports/INDEX.md`](reports/INDEX.md)

## 무엇을 만들었나

- **가치 엔진.** 잔여이익모형(장부가 + 초과이익의 현재가치). R&D와 판관비 일부를 산업별 파라미터(Ewens·Peters·Wang 2025)로 자본화해 장부와 이익을 고쳐 쓰고, 초과 ROE가 산업 평균으로 돌아오는 속도(지속성 ω)를 가정하지 않고 수천 기업의 실제 기록에서 기업 특성별로 추정합니다.
- **가격 분해.** log(가격/가치)를 월별 횡단면 회귀로 구조적 수요(기관·패시브 지분), 일시 수급(펀드 흐름), 모멘텀, 펀더멘털 기대, 산업, 잔차로 나눕니다. 진단용입니다.
- **역산과 정방향.** 같은 엔진을 거꾸로 풀어 가격이 요구하는 10년 성장 g*, 지속성 ω*, 초과수익 유지 기간 T*를 구하고, 문헌의 자본화 파라미터 여섯 조합으로 g*의 구간을 붙입니다. 앞으로 풀면 내 매출·이익률 경로가 주는 목표주가와 수익률이 나옵니다. 적자 기업은 이익률 경로를 주면 요구 매출 성장을 풉니다.
- **도구.** 데스크톱 계산기(PySide6)와 명령줄, 데이터 품질 불변식 37개(키 유일성·시점 규칙·항등식·값 범위·입력 신선도), 의존성 순서를 아는 월별 갱신 실행기.

## 정직한 결과

이 도구는 **예측 모형이 아닙니다.** 구현 전에 고정한 판정 기준으로 2014-06~2026-09 표본(13F 내재가격 분기 수익률, 상장폐지 포함, Fama-MacBeth)에서 검정한 결과, 분해의 어느 성분도, 벤치마크(B/M, E/P, Bartram·Grinblatt 동료내재가치, ICC)도 이후 수익률을 예측하지 못했습니다. 사전 등록한 폐기 기준에 걸렸고 그대로 기록했습니다([`reports/phase3_validation.md`](reports/phase3_validation.md), 판정 기준은 [`docs/design_spec_20260905.md`](docs/design_spec_20260905.md) 2.5절).

남는 용도는 알파가 아니라 **판단 위생**입니다. 가격이 전제하는 가정을 숫자로 번역하고, 그 가정이 과거에 실현된 비율과 비교하고, 실적이 나온 뒤 전제를 채점하는 것. 그 전제를 믿을지는 사용자의 판단입니다. 도구는 그 판단의 옳고 그름을 말하지 않습니다.

## 예시 — 엔비디아, 2026-09-30

```
python scripts/what_if.py --ticker NVDA
```

| 항목 | 값 |
|---|---|
| 가격이 요구하는 10년 이익성장 g* | 연 20.7% (자본화 가정을 바꿔도 20.1~21.5%) |
| 그 정도를 요구받은 기업이 이후 3년간 실제로 낸 비율 | 요구 20~30% 구간 전체 9%, 직전 1년에 이만큼 자란 무리 안에서는 21% |
| 내 성장 전망이 연 15%라면 이 가격이 주는 연 수익률 | 8.5% (20%면 10.8%) |
| 정규화 이익(5년 평균 이익률) 기준 요구 성장 | 연 24.7%, 이익 국면 표시 "피크" |

읽는 법은 세 문장입니다. 가격이 전제하는 성장이 얼마인가. 그게 과거에 얼마나 흔했나. 내 전망이면 수익률이 얼마인가. 자세한 과정은 [`docs/walkthrough.md`](docs/walkthrough.md)에 흑자 초대형주·적자 기업·매수일 대조 세 경우로 적었습니다.

## 바로 실행

클론 직후 계산기와 명령줄이 돕니다. 최신 월의 축약 테이블(`app/data/`, 19MB)이 저장소에 들어 있기 때문입니다. 전체 파이프라인 재계산에는 약 17GB의 원본이 필요하고 [`data/README.md`](data/README.md)에 입수 방법이 있습니다.

```bash
pip install -r requirements.txt            # Python 3.11
python -m app                              # 데스크톱 계산기
python scripts/what_if.py --ticker NVDA    # 한 종목의 역산·수익률 축·추이
python scripts/what_if.py --ticker IREN --solve-growth --margin 30,35,40 --years 5   # 적자 기업: 이익률 경로 → 요구 매출 성장
python scripts/what_if.py --ticker AAPL --since 2024-12-31                          # 매수일의 전제 vs 이후 실현
python -m pytest tests -q                  # 단위 테스트
python app/selftest.py                     # 계산기 자체 점검 (화면 없이)
```

## 저장소 구조

| 경로 | 내용 |
|---|---|
| `sfv/` | 파이프라인 모듈 28개. 원본 파싱(`xbrl_extract`, `f13`, `nport`, `ftd`) → 패널(`xbrl_panel`, `universe`) → 가치(`intangibles`, `persistence`, `rim`, `growth_rim`) → 분해·검증(`demand`, `decompose`, `validate`) → 역산(`implied`, `expectations`) → 계산 라이브러리(`calc`, `store`, `live`) → 점검·출력(`selfcheck`, `report`) |

## 데이터와 규칙, 한계

- 재무는 SEC XBRL의 **최초 보고치**만, 공시일 이후에만 씁니다. 13F 보유는 분기말 + 46일부터, 지속성 추정치는 결과 연도 다음 해 6월 30일부터. 검증 수익률은 13F 내재가격으로 만들어 상장폐지 종목을 포함합니다(yfinance와 상관 0.996).
- 유니버스는 미국 비금융 보통주, 시총 3억 달러 이상, 월별 약 1,400~1,900종목. 금융업은 제외.
- 한계: 예측 모형이 아닙니다. 표본은 12년, 한 번의 강세장입니다. 경계값(지속성 ≤ 0.90 등)은 가치 폭발을 막는 대가로 슈퍼스타를 체계적으로 낮게 평가합니다. 자본화 파라미터를 바꾸면 종목 가치는 중앙값 46% 움직이지만 상대 순위(순위상관 0.92~0.98)와 요구 성장 구간은 안정적이라 판단은 점이 아니라 구간으로 합니다. 초대형주의 횡단면 판정은 검증된 효력이 없습니다.

## 작업 방식

2026년 9월 약 2주. 설계 명세를 쓰고 판정 기준을 구현 전에 고정한 뒤, 데이터 파이프라인부터 도구화까지 단계마다 결과 리포트를 남기며 진행했습니다. AI 코딩 보조 도구(Claude Code)를 사용했고, 모형과 방향의 결정은 제가 했습니다. 잔여이익모형과 로그 항등식 채택, 산업별 무형자산 자본화, 감쇠 목표를 산업 중앙값으로 두고 자본비용 대안을 하한으로 함께 보고, 사전 등록 기준과 폐기 판정의 수용, 수요 성분의 유지, 예측 검정을 월별 실행에서 분리, 역산을 주 용도로 전환, 초대형주 결론을 소형주로 일반화하지 않는 구간 규칙, 데스크톱 계산기의 형태. 코드 리뷰와 그 과정에서 고친 결함, 한 번의 운영 사고 기록은 [`reports/code_review.md`](reports/code_review.md)에 있습니다.

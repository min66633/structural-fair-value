# 모형 민감도 — 수요 측정 오차와 경계값

> 생성 2026-09-13. 두 가지 판단이 결과를 얼마나 움직이는지 수치로 답한다.
## 1. 수요 변수를 통째로 빼면 무엇이 바뀌는가

> 월별 횡단면 회귀를 수요 블록(X_S, X_T) 포함·제외로 두 번 돌려 비교. 기업-월 200,026, 월 140개 (2014-09-30~2026-04-30).

|                  | 값                  |
|:-----------------|:-------------------|
| 잔차 분산 몫 (수요 포함)  | 0.442              |
| 잔차 분산 몫 (수요 제외)  | 0.460              |
| δ_S / δ_T 분산 몫   | 0.020 / 0.001      |
| 두 잔차의 상관         | 0.9805 (최저 0.9571) |
| 잔차의 평균 절대 변화     | 0.0816             |
| 같은 값, 잔차 표준편차 대비 | 13.7%              |

**읽기.** 수요 모듈 전체를 없애도 잔차는 상관 0.98로 거의 그대로이고, 크기로는 자기 표준편차의 15% 정도 움직인다. 수요 측정이 틀리면 바뀌는 것은 δ_S와 ε의 경계이지 둘의 합이 아니다. 합은 항등식이라 언제나 log(P/V_F)와 정확히 같다.

더 중요한 것은 **V_F와 역산이 수요 변수를 아예 읽지 않는다**는 점이다. 잔여이익 가치, 지속성 추정, 성장 단계, 종목별 ω*·T*·g* 어느 것도 13F·N-PORT를 입력으로 쓰지 않는다(`sfv/implied.py`만 예외로 읽지만 ω* 해와는 무관한 보고용 열에만 쓴다). 그래서 수요 측정 오차는 도구의 주 출력에 전파되지 않는다.

한계: 패시브 지분은 펀드명 기반이라 하한이다(Chinco·Sammon 2024는 실질 패시브를 33% 수준으로 본다). 따라서 '구조적 수요가 프리미엄의 작은 부분만 설명한다'는 결론은 **하한 해석**이다. 다만 δ_S의 분산 몫이 2.0%라 두세 배로 늘려도 그림이 바뀌지 않고, 측정이 더 나은 스펙 B(N-PORT 지수 비중 포함)에서도 3.9%였다.

## 2. 경계값은 실제로 얼마나 자주 걸리는가

> 기업-월 248,557. 경계값은 모형에서 사람이 정한 유일한 숫자이며, 제약 없는 회귀가 만드는 가치 폭발(아마존 2018년 8조 달러)을 막기 위한 것이다.

|                      | 걸리는 비율   | 시총가중   |   원값 중앙값 |
|:---------------------|:---------|:-------|---------:|
| 지속성 ω > 0.9          | 0.4%     | 2.8%   |    0.449 |
| 장기 초과 ROE |x∞| > 0.1 | 15.1%    | 70.3%  |    0.045 |
| 현재 초과 ROE |x0| > 0.5 | 5.4%     | 12.0%  |    0.087 |
| 장부 성장 1년차 > 0.25     | 2.7%     | 8.3%   |    0.039 |
| 터미널 계수 q > 0.92      | 0.0%     | 0.0%   |    0.423 |
| 하나라도 걸림              | 20.1%    | 71.9%  |          |

최신 월(2026-09-30) 1,878종목 중 경계에 걸린 비율은 25.0%, 시총가중으로는 **85.9%**다.

**읽기.** 종목 수로는 소수지만 시가총액으로는 대부분이다. 경계값이 대형 고수익 기업에서 집중적으로 걸린다는 뜻이고, 이것이 '경계값이 슈퍼스타를 체계적으로 낮게 평가한다'는 한계의 실제 크기다. 엔비디아의 log(P/V_F)가 1.59일 때 그중 얼마가 진짜 프리미엄이고 얼마가 경계값 때문인지는 분리되지 않는다.

그래서 대형주에서는 점 추정 가치 대신 역산을 읽어야 한다. 역산은 '이 가격이 맞으려면 경계 밖으로 얼마나 나가야 하는가'를 직접 답한다. 엔비디아의 요구 지속성 ω* 0.98은 모형 상한 0.90을 크게 넘고, 그 격차 자체가 답이다.
